## 1. The 12-Class Cognitive Failure Taxonomy

| Failure Class | Root Cause Diagnostic | ASCENDANT ∞ Automated Recovery Protocol |
| :--- | :--- | :--- |
| **1. Knowledge Failure** | Epistemic void in World Model | Trigger Question Genesis $\to$ Inquiry DAG. |
| **2. Reasoning Failure** | Invalid deductive inference | Trigger Multi-Path Reasoner + Adversarial Critique. |
| **3. Strategy Failure** | Ineffective cognitive approach | Trigger Cognitive Genesis Pipeline $\to$ Synthesize new strategy. |
| **4. Capability Failure** | Missing tool or execution cell | Trigger Capability Birth Pipeline $\to$ Sandbox prototype $\to$ Validate. |
| **5. Tool Failure** | Subprocess error in sandbox | Catch exception, record into Failure Memory, formulate patch. |
| **6. Memory Failure** | Retrieval miss or index error | Re-index 7-domain stores and expand semantic search breadth. |
| **7. World-Model Failure**| Stale prediction / Reality drift | Ingest direct observation, compute reality delta, update epistemic state. |
| **8. Planning Failure** | Cycle in dependency DAG | Re-topological sort, prune cyclic edge, recreate acyclic plan. |
| **9. Verification Failure**| Invariant violation in claim | Reject conclusion immediately, flag contradiction in Evidence Ledger. |
| **10. Calibration Failure**| High Brier score discrepancy | Apply Meta-Prediction calibration penalty, recalibrate success prior. |
| **11. Learning Failure** | Stagnant learning curve | Third-order bottleneck analysis $\to$ Mutate curriculum parameters. |
| **12. Meta-Learning Failure**| Negative learning acceleration | Revert curriculum mutation $\to$ Increase exploration ratio. |
