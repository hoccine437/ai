## 3. Substrate Architectural Manifest

| Component Directory | Primary Engine Class | Primary Responsibility |
| :--- | :--- | :--- |
| `zerion/cognitive_autopoiesis/` | `CognitiveAutopoiesisEngine` | Diagnostic reflection optimizing the strategy discovery and capability acquisition process itself. |
| `zerion/counterfactual/` | `CounterfactualEngine` | Simulation and causal intervention answering *"What if X changed / was false?"*. |
| `zerion/cognitive_immune/` | `CognitiveImmuneSystem` | Multi-barrier static, sandbox, and invariant defense protecting trust root and integrity. |
| `zerion/cognitive_genome/` | `CognitiveGenome`, `GenomeManager` | 22-dimensional behavioral genome, schema validation, and phenotype derivation. |
| `zerion/cognitive_genesis/` | `CognitiveGenesisPipeline` | 10-stage autonomous strategy synthesis with AST analysis and adversarial stress testing. |
| `zerion/learning_to_learn/` | `LearningToLearnEngine` | 2nd-order learning acceleration and 3rd-order learning process bottleneck optimization. |
| `zerion/strategy_evolution/` | `StrategyEvolutionEngine` | Lineage tracking, higher-order composition, and non-destructive retirement with rollback. |
| `zerion/meta_prediction/` | `MetaPredictionEngine` | Pre-task forecasting and post-execution Brier calibration. |
| `zerion/adaptive_cognition/` | `AdaptiveCognitiveController` | Multi-tier compute allocation (REFLEX, FAST, NORMAL, DEEP, EXPERIMENTAL). |
| `zerion/world/` | `WorldModel`, `WorldTracker` | 8 epistemic categories (`OBSERVED`, `MEASURED`, `INFERRED`, `PREDICTED`, `HYPOTHESIZED`, `ASSUMED`, `UNKNOWN`, `CONTRADICTED`). |
| `zerion/questions/` | `QuestionGenesis`, `QuestionScorer` | 9 question modalities prioritized by expected information gain over cost and risk. |
| `zerion/capabilities/` | `CapabilityBirthPipeline` | 9-stage capability synthesis with generalization validation across domain-shifted variants. |
| `zerion/engine.py` | `AscendantEngine` | Master coordinator executing the 25-stage continuous developmental flywheel. |
